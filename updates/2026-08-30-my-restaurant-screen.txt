================================================================
1. NEW SCREEN - MyRestaurantScreen
================================================================
frontend/src/screens/Owner/MyRestaurantScreen.js

  Data: calls getRestaurantInfo() (api/services/home.js -> POST
  /api/get-restaurant-info/), which returns { restaurant, location }.
  Reloaded on every screen focus via useFocusEffect, so edits made on
  RestaurantInformationScreen show up straight away.

  Three states:
    - loading            -> spinner
    - no restaurant yet   -> empty state: store icon, "No information
                             yet", a short line, and an
                             "Add Restaurant Information" button that
                             opens RestaurantInformationScreen
    - restaurant present  -> the full details:
        * cover photo (or "No cover photo" placeholder)
        * logo overlapping the cover (or a placeholder icon)
        * restaurant name + description
        * Contact card:  Address, Contact Number, Email
        * Location card: City, Province, Region, Country,
                         Latitude, Longitude
        * "Edit Information" button -> RestaurantInformationScreen
        * "Added on <date>" footnote (from created_at)

  Every field that is blank renders a muted "Not provided" so nothing
  is silently hidden. Small DetailRow component renders each
  label / value pair; formatDate() turns created_at into a readable
  date.

frontend/src/styles/MyRestaurantScreenStyle.js
  New stylesheet - header, centered loading/empty block, cover + logo,
  detail cards and rows, edit button. Uses the existing colour tokens
  and the Ezra font family like the rest of the app.
